2. Description of Service

Landline is a mobile application designed to help users manage their phone usage. Like an old landline phone, your distracting apps stay disconnected by default and you "dial up" when you intentionally want to use them. The App provides:

  • Landline Mode: an always-on blocking state for the apps you select
  • Dial-up sessions: temporary, time-limited access to blocked apps
  • Optional mindfulness activities and puzzles (such as math, box breathing, and gratitude prompts) to start a dial-up session
  • Scheduling and automation tools
  • Optional physical triggers: NFC tags and QR codes that start or end Landline Mode
  • Optional location-based activation: automatically start Landline Mode when you arrive at a saved place (such as home)
  • Session status via notifications, Live Activities, and the Dynamic Island

The App uses Apple's Screen Time API to enable blocking functionality.
